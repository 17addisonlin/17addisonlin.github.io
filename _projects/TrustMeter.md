## Overview

TrustMeter brings news classification and statement checking into one web application. It accepts article text or a URL, and can check a single claim against Wikipedia evidence.

## What it does

- Classifies news articles and displays prediction confidence.
- Checks statements as supported, refuted, or lacking enough information.
- Presents evidence alongside the result.
- Uses a FastAPI backend with transformer models.

## Built with

Python, FastAPI, PyTorch, Hugging Face Transformers, and scikit-learn, with a browser interface built in HTML, CSS, and JavaScript.

The [project repository](https://github.com/17addisonlin/AI-Powered-Fake-News-Detection) contains setup instructions, model information, and the development roadmap.
