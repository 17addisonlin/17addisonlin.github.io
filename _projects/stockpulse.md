## Overview

StockPulse is a stock data dashboard for exploring price movements and keeping track of tickers in one place.

## What it does

- Searches for tickers and retrieves current price data.
- Displays line and candlestick charts with volume overlays.
- Supports date range and interval controls.
- Saves a watchlist in the browser and tracks price alerts.

## Built with

React, Vite, Tailwind CSS, and Plotly on the frontend, with a Node.js and Express backend.

The [project repository](https://github.com/17addisonlin/Stock-Data-Visualization-Dashboard) contains installation instructions and the roadmap.

Interface inspiration: [Michael Wang](https://dribbble.com/wangmander). Charts use [Plotly](https://plotly.com/javascript/).
