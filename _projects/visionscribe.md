## Overview

VisionScribe generates image captions from uploaded photographs. It also offers a social caption mode with control over tone, emojis, and hashtags.

## What it does

- Accepts images through drag-and-drop or a file picker.
- Shows a preview before generating a caption.
- Uses vision-language models to describe images.
- Produces social captions with configurable style.

## Built with

Python, FastAPI, PyTorch, and Hugging Face Transformers, with an HTML, CSS, and JavaScript interface.

The [project repository](https://github.com/17addisonlin/AI-Powered-Image-Captioning-System) includes environment setup, model dependencies, and usage instructions.
